# Catalog Service

[S2-318](../../services/catalog-service/README.md) incorpora la base operativa
de Catalog, propietario de clientes, proveedores, productos y servicios.
S2-319 y las historias posteriores incorporan las capacidades de negocio.

Los CRUD de clientes, proveedores y artículos existen. S2-456 a S2-459 amplían
fichas y relaciones bajo el contrato v0.8. Inventory proveerá existencias,
Sales la ficha financiera de cliente y Expense el saldo de proveedor.
